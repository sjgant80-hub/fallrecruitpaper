## For the end user

Generate, preview, and issue UK recruitment documents from 8 templates. Locked regulatory clauses preserve statutory wording from the Conduct Regulations 2003, AWR 2010, and IR35 off-payroll rules.

### Templates

| Code | Template | Category |
|---|---|---|
| TOB-H01 | Terms of Business (Hirer) | Terms |
| TOB-C01 | Terms of Engagement (Candidate) | Terms |
| AS-01 | Assignment Schedule | Assignment |
| AWR-01 | AWR Notification Letter | Compliance |
| IR35-01 | IR35 SDS Cover Letter | Compliance |
| INT-01 | Interview Confirmation | Placement |
| OFR-01 | Offer Confirmation Letter | Placement |
| REF-01 | Reference Request | Admin |

### Key rules

- **Conduct Regulations 2003**: written terms before services (Reg 17/18), transfer fees (Reg 10)
- **Agency Workers Regulations 2010**: 12-week equal treatment, day-one facility rights
- **IR35 / Off-payroll**: SDS cover letter with appeal rights
- **Employment Agencies Act 1973 s.6**: no charging work-seekers
- **UK GDPR**: reference processing, data retention notices
